# PathFinder-AI

## AI-Powered Personalized Learning Path Recommender

PathFinder-AI is an intelligent learning assistant that generates personalized learning roadmaps based on a learner's goals, interests, skill level, and learning history.

## Problem Statement

Online learning platforms provide thousands of courses, but learners often struggle to determine what to learn, in what order, and which resources best match their goals. PathFinder-AI solves this problem by generating adaptive and personalized learning paths.

## Features

### Conversational AI Interface
- Learners describe their goals in natural language.
- AI understands objectives and learning preferences.

### Learner Profiling Engine
- Captures interests, experience level, completed courses, and career aspirations.
- Identifies strengths and skill gaps.

### Recommendation Engine
- Suggests courses, projects, certifications, and learning resources.
- Provides explainable recommendations.

### Personalized Learning Path Generator
- Creates structured learning roadmaps.
- Includes prerequisites, milestones, and estimated timelines.

### AI Learning Assistant
- Explains recommendations.
- Answers learner queries.
- Adapts suggestions based on progress and feedback.

### Progress Dashboard
- Tracks completed milestones.
- Visualizes skill growth.
- Recommends next actions.

## Tech Stack

- Frontend: React + Vite
- Backend: FastAPI
- AI/ML: Python, LLMs, Recommendation Models
- Database: PostgreSQL / SQLite
